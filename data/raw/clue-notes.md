# clues 創作原則（A2 語料線）

- 每條成語至少 3 則線索：必含 1 則「釋義」（白話猜謎語氣，非照抄 meaning 欄）＋至少 2 則創意型。
- 創意型優先順序：有明確典故（insight 欄有「出自《…》」的 26 條）→ 用「典故」講情節、不點名成語；沒有典故的（34 條）→ 用「情境」（台灣校園/生活場景）＋「急轉彎」補足。
- 「諧音」僅在雙關真的成立時使用（本次僅用於 p0005 畫龍點睛，取自 SCHEMA.md 給的示例）。
- 硬規則以程式驗證，不用肉眼逐條檢查：`data/raw/validate-clues.mjs` 檢查
  1. clues ≥ 3、含 1 則釋義、創意型 ≥ 2
  2. style 皆在枚舉內
  3. 線索文字不得含完整成語、不得含成語中任兩個相鄰字連用
  4. 每則 ≤ 45 字
  5. 無明顯簡體字（比對常見簡體字清單）
- `data/raw/build-clues.mjs`：clueMap（60 條）就地寫回 `data/phrases.json` 的 `clues` 欄位，其餘欄位不動。跑法：
  ```
  node data/raw/build-clues.mjs
  node data/raw/validate-clues.mjs
  ```
- 首次跑驗證抓到 2 個違規並已修正：
  - p0020 目不轉睛 釋義句含「不轉」→ 改「眼珠子一動也不動」
  - p0045 四面楚歌 釋義句含「四面」→ 改「四方全遭圍困」
