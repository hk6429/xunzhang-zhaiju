# 尋章摘句隱私權政策

更新日期：2026-09-01

「尋章摘句」是一款中文尋詞與閱讀學習 App。本政策說明 App 在訪客模式與登入同步模式下如何處理資料。

## 我們處理哪些資料

### 不登入時

- 遊戲進度、錯題、圖鑑、每日任務與個人例句只保存在使用者裝置上。
- App 不會將訪客遊戲資料傳送至尋章摘句的同步服務。

### 使用 Apple 或 Google 登入時

為提供 iPhone、iPad 與 Web 共用進度，App 會處理：

- 由登入供應商與帳號識別碼衍生的內部使用者識別碼。
- App 安裝時隨機產生的裝置識別碼。
- 遊戲進度與操作事件，例如關卡星數、已找到的詞句、墨滴餘額、每日任務、錯題及世界事件進度。
- 維持登入安全所需的工作階段與權杖雜湊資料。

Apple／Google 的身分權杖只用於驗證登入，不作廣告或分析用途。同步服務不保存登入供應商回傳的姓名、電子郵件、頭像或原始身分權杖。

個人例句與使用情境永遠只保存在本機，不會加入雲端同步。

## 使用目的

上述資料只用於：

- 提供遊戲、保存與跨裝置同步進度。
- 驗證登入、維持工作階段及防止濫用。
- 回應使用者主動提出的匯出或刪除帳號要求。

## 不追蹤、不販售

尋章摘句沒有廣告，不使用跨 App／網站追蹤技術，也不販售或出租個人資料。

## 服務供應商

同步功能使用 Cloudflare 提供 API 執行與安全防護，並使用 Turso 儲存同步資料；Apple 與 Google 僅在使用者選擇相對應的登入方式時參與身分驗證。這些供應商會依其服務條款與隱私權政策處理必要資料。

## 保存、匯出與刪除

- 雲端帳號與同步資料保存至使用者在 App 內刪除帳號為止；依法令或資安需求必須保存者不在此限。
- 登入後可在 App 內匯出雲端資料、登出或刪除帳號。
- 刪除雲端帳號與清除裝置上的本機資料是兩項分開確認的操作，避免誤刪。
- 移除 App 通常會刪除裝置上的一般本機資料；保存在系統鑰匙圈的裝置識別資料可能依作業系統行為保留。

## 兒少使用

本 App 適合一般學習者使用，不要求填寫生日、學校、班級、電話或地址，也不刻意蒐集兒童的聯絡資料。若監護人認為兒少資料遭不當處理，可透過下方方式聯絡。

## 資料安全與政策更新

我們採用加密連線、短效存取權杖、更新權杖輪替及權限檢查等措施保護資料，但任何網路服務都無法保證零風險。本政策若有重大變更，將更新本頁日期並於適當位置通知。

## 聯絡方式

隱私權、資料匯出或刪除問題，請前往[尋章摘句支援頁](https://xunzhang-zhaiju.pages.dev/support.html)查看處理方式。一般問題可使用公開回報表單；請勿在公開內容中填寫姓名、電子郵件、學校、帳號識別碼或其他個人資料。
