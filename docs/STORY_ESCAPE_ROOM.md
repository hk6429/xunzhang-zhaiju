## 壹、 世界觀背景（World Lore）

### 1. 緣起：天道文字崩解與名陣異化
商周易代之際，三界劫波翻湧，封神榜現世引發天道靈氣劇烈震盪。文曲星君所司掌之「天地文字靈脈」四散崩解，化為無數具有通天神力的字元碎片。

太古名陣——**先天八卦陣、九曲黃河陣、十絕凶陣、朝歌幻鏡陣、誅仙萬仙陣**——受文氣異化，不再只是單純的殺伐戰場，而是化作一座座自成天地、重重交錯的**「封神文字密室」**。神魔仙妖、西岐將領、殷商太師，皆被禁錮於由字格盤面所構築的玄機棋局之中。

### 2. 玩家使命：天命「尋章使」
玩家身負文曲宿命，化身為**「尋章使」**。手持匯聚天地文氣的「通天靈筆」，懷揣「太上靈墨」，穿梭於各座凶險奇詭的密室之間。

唯有通曉字意、明辨典故、洞察情境，在縱橫交錯的字陣中**尋章摘句**，將四散的天道真言點亮歸位，方能破開陣眼生門，解救受困群仙，終結密室劫難，功德圓滿以登封神金榜！

### 第 1 章：崑崙秘境·太公初布八卦陣（關卡 1–10）

* **陣法名稱**：先天八卦文字陣
* **守陣導師**：姜子牙（太公望）
* **密室場景**：崑崙山玉虛宮側殿·乾坤八卦石室
* **環境氛圍**：仙霞繚繞，白鶴長鳴，四周石壁刻有乾、坤、震、巽、坎、離、艮、兌古篆。室內青燈古卷，靈氣氤氳，祥和寧靜。
* **脫逃目標**：參悟八卦方位，於 5×5 基礎字盤及 7×7、8×8 十字交錯盤中尋得常用成語，點亮陰陽魚陣眼，開啟通往下界的密室之門。
* **天道法則**：
  * **時辰限制**：無時限（`timeLimit: null`），可悠然沉思。
  * **靈墨限制**：無提示次數上限（`hintCap: null`），靈泉無限。
  * **線索風格**：以白話「釋義」為主，輔以生活「情境」與趣味「急轉彎」。
* **敘事對白**：
  > **開場**：「小友，此乃老夫布下的八卦字陣。莫慌，天地文章始於一筆一劃，且隨老夫靜心摘句。」

## 肆、 密室逃脫四大天道核心機制文案

```
┌─────────────────────────────────────────────────────────────┐
│                      天道字陣核心循環                        │
│                                                             │
│   [審題觀線索] ──> [視盤面尋真言] ──> [拖選 / 填入答案]    │
│         ▲                                   │               │
│         │                                   ▼               │
│   [賺墨水補氣] <── [靈墨道法提示]     [點亮陣眼生門]        │
│                                             │               │
│                                             ▼               │
│                                      [成功脫逃密室]         │
└─────────────────────────────────────────────────────────────┘
```

### 1. 天道靈墨（The Ink Engine）
* **世界觀概念**：文曲星君遺留於筆端的純陽文氣。
* **消耗規則**：
  * **圈首字（點明陣眼）**：消耗 1 墨。照亮目標首字座標。
  * **閃現整句（雷光顯形）**：消耗 3 墨。通篇路徑高亮 2 秒。
  * **直接揭示（天神破壁）**：消耗 5 墨。強行填入該句，但本關星等封頂 1★，且該句不入摘句圖鑑。
* **文曲試煉（賺墨水）**：
  * 釋義選擇題：答對 +1 墨。
  * 挖空填字題：答對 +2 墨。

### 2. 時辰沙漏（The Hourglass Timer）
* **世界觀概念**：混元金斗與萬仙天碑的時空壓迫力場。
* **時限機制**：
  * 第 1 章無時限；第 2 章 300–330 秒；第 3 章 270–300 秒；第 4 章 270–300 秒；第 5 章 240–300 秒。
  * **時空凍結**：點開知識卡、文曲試煉答題、通關結算、或超時彈窗時，沙漏暫停。
  * **紅光脈動（最後 20%）**：倒數計時器閃爍赤紅神光，伴隨 NPC 危機語音。
  * **時辰已到（超時封閉）**：密室合閉，本關盤面與進度重置，可無損重新挑戰。

### 3. 陣法禁制（Hint Quota Pressure）
* **世界觀概念**：古陣煞氣封鎖尋章使的神識感應。
* **次數限制**：
  * 第 1 章：不限（自由探索）。
  * 第 2 章：上限 3 次。
  * 第 3 章：上限 2 次。
  * 第 4 章：上限 1–2 次。
  * 第 5 章：上限 1 次（宗師決戰，幾近純盲解）。

### 4. 摘句金榜圖鑑（Collection Vault）
* **世界觀概念**：解救散佚天道文字後，化為玩家文德修為的金光寶冊。
* **規則**：
  * 凡於密室中憑實力找到或填對的成語/諺語，永久收錄。
  * 點擊可隨時重溫白話釋義、生活用法賞析與真實出處典籍。
  * 即使超時重新挑戰，已收錄的圖鑑進度絕不回收。
