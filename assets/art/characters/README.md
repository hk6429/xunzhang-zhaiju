3. **100% 純原創設計 (Original IP)**：

## 📂 檔案結構與調用方式

- `characters-art.json`：立繪結構化元數據（色票、特色、法寶）。
- `character-registry.js`：專案主角色註冊表，支援 `artIllustration`、`artPortrait` 與動態 SVG 表情包切換。
- `gallery.html`：立繪畫廊展示頁面，可直接開啟檢視 9 位角色的 1:1 Q 版立繪與典故介紹。
